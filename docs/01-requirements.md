# 需求

运营人员输入主题、预算、截止时间，获得任务计划、依赖与步骤状态、工具结果、费用合计及已保存方案，或明确未完成原因。仅本地合成内容活动，不接发布/采购平台。

必须验收：正常完成；缺预算或截止时间；工具失败；预算超限；重复执行。扩展验收包括 12→8 的真实模型重规划、截止时间不足、保存失败、执行上限、失败步骤续跑、并发幂等与输入内容冲突。

模型选择动作、观察工具结果并重规划。服务端强制预算、截止时间和依赖，模型不能凭 finish 宣称成功。成功工作要保留，失败步骤不能记为成功。缺必填信息在进入模型前返回 needs_information。

费用与耗时采用合成表。截止时间检验支持当前UTC实时钟或显式--now模拟起点，不宣称已完成真实制作。活动方案包括主题、当前策略、任务计划、素材和脚本产物。真实模型负责规划，本地脚本生成器是模板适配器。
