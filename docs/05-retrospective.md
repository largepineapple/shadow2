# 工程复盘与待完善事项

技术要点：预算估算与已发生费用必须分开；重规划不能抹掉已付出的成本。成功步骤复用、脚本依赖、最终保存及失败状态必须以数据库为准，不能依赖模型自报。恢复执行需要把持久化快照重新传给模型。

实际调试：首轮示例全部场景断言满足，但 Windows 临时目录清理失败，因为 sqlite3 的事务上下文并不负责关闭连接。改用 contextlib.closing 后重新运行，runner 正常退出。该问题及修复基于实际运行，不代表候选人的个人经历。

下一步可扩展真实素材检索、真实文案生成适配器、多种活动策略与业务日历；真实远程收费工具需要独立处理幂等与对账，不能把当前本地事务保证直接外推。当前不扩展生产鉴权或发布系统。
